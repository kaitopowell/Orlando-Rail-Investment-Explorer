# Shared map panel accordion

Captured in Chromium with live CARTO tiles, reduced motion enabled, Population and Equity enabled, Rail network open at its default $10B scenario, and a pitched camera. Population's columns are suppressed; the flat green choropleth is Equity. All captures reported BASEMAP LIVE without page errors.

- [1366 × 768](panels-1366.png): the column scrolls independently above the map buttons.
- [1920 × 1080](panels-1920.png): Rail network and collapsed Population/Equity headers fit together.
- [380 × 844](panels-380.png): phone layout with clear map controls and status badge.

Automated tests also check keyboard accordion operation, population restoration, opacity, Equity/rail ordering and no horizontal overflow. These captures do not establish physical-phone or cross-browser support.
